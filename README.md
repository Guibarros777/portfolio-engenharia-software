## Sobre o projeto

O projeto foi desenvolvido como uma página web estática, com identidade visual de dashboard, tema escuro e elementos interativos. Ele reúne, em uma experiência responsiva, informações sobre a graduação, semestres cursados, histórico profissional e trabalhos acadêmicos.

### Destaques

- Interface moderna com efeito de vidro
- Fundo animado com partículas
- Menu responsivo
- Animações de entrada e contadores
- Efeito 3D em cartões e botões
- Barra de progresso da página
- Galeria com lightbox
- Navegação ativa por seção
- Suporte à preferência de movimento reduzido

## Seções

## Executando localmente

Não é necessário instalar dependências ou configurar um servidor especial.

### Opção 1 — abrir diretamente

Abra o arquivo `index.html` em um navegador.

### Opção 2 — servir com Python

```bash
git clone https://github.com/Guibarros777/portfolio-engenharia-software.git
cd portfolio-engenharia-software
python -m http.server 8000
```

Depois, acesse:

```text
http://localhost:8000
```

### Opção 3 — Live Server no VS Code

1. Abra a pasta do projeto no VS Code.
2. Instale a extensão **Live Server**.
3. Clique em **Go Live** na barra de status.

## Publicação com GitHub Pages

Este projeto pode ser publicado com GitHub Pages:

1. Acesse **Settings** no repositório.
2. Entre em **Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Clique em **Save**.
